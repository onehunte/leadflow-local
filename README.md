# LeadFlow Local

Aplicativo desktop para prospecção, captura e gestão local de leads.

## Download para Windows

Baixe exclusivamente o instalador oficial na página da versão:

[Baixar LeadFlow Local 1.2.4](https://github.com/onehunte/leadflow-local/releases/tag/v1.2.4)

Requisitos: Windows 10 ou Windows 11 de 64 bits e conexão com a internet para pesquisas, mapas e envio de e-mails.
